# SARA - Snake-Assisted Rescue Automaton

Snake-style underground search-and-rescue robot concept.
**Vishwakarma Awards 2026-27, Stage 2** - Application ID: **VK26-AU-PAI-0062**
Theme: Physical AI for Resilience and Inclusion / AI for Disaster Resilience

**Team:** Rahul Dev, Ankush Kumar, Rahul Agrawal, Anjil Ghosh

## How this was made (please read)
The 3D model is generated by a parametric Python script (`cad/sara_cad.py`, CadQuery) that was
developed with AI assistance. The 2D drawing and the diagrams are generated from that model or from
scripts in this repo. **No hardware has been built or tested yet.** Prices are estimates.

## Design in one paragraph
Head (camera, thermal, CO2, mic, Pi Zero 2 W) - 4 cardan joints with tendon cables pulled by servos in the tail -
3 traction modules with belts on 4 sides (12 N20 motors) - tail (ESP32, 2x18650, drivers).
A tether carries data; a separate Dyneema retrieval line with a rear eyebolt lets operators pull SARA back
even if all electronics fail.

## Rebuild
```
pip install cadquery matplotlib numpy shapely
python cad/sara_cad.py out          # parts, STEP/STL, report, meshes
python cad/render.py out            # renders
python cad/make_2d_drawing.py out   # 2D drawing
python docs/make_pinout_sheet.py    # pin + power sheet
```

## Folders

- `renders/` isometric, exploded, cutaways
- `docs/` 2D drawing, wiring diagram, pin sheet, BOM, FMEA
